# GeniusFiles Legal Hub

Crée un mini-site public officiel pour l'application mobile GeniusFiles destiné uniquement à présenter ses documents légaux.

Le site doit être extrêmement simple, professionnel, moderne et parfaitement adapté aux smartphones.

Il doit contenir une page d'accueil très minimaliste avec :

- le logo ou le nom GeniusFiles ;
- un court texte indiquant qu'il s'agit de l'espace officiel des informations légales de GeniusFiles ;
- un bouton « Politique de confidentialité » ;
- un bouton « Conditions d'utilisation ».

Prépare également deux pages distinctes :

- « Politique de confidentialité »
- « Conditions d'utilisation »

Pour le moment, laisse le contenu de ces deux documents facilement remplaçable afin que je puisse y intégrer les versions définitives ultérieurement.

Le site doit rester exclusivement consacré aux informations légales. N'ajoute ni blog, ni formulaire, ni compte utilisateur, ni publicité, ni fonctionnalité inutile.

La navigation entre les trois pages doit être claire et fonctionner correctement sur mobile et ordinateur.

Conserve une apparence sobre, lisible et cohérente avec l'identité premium de GeniusFiles.
